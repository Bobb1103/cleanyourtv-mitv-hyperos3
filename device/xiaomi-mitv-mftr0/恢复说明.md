# 恢复说明（速查）

完整操作手册见 [README.md](README.md)，澎湃 3.0 的适配背景见
[../../docs/mitv-hyperos3.md](../../docs/mitv-hyperos3.md)。这里只放最常用的几段命令。

日期：2026-10-25 ｜ 机型 MiTV-MFTR0（freeguy）｜ 固件 OS3.0.107.0.UFTMATV（Android 14 / HyperOS TV 3）

## 改动后的状态

- 桌面：CleanYourTV 2.7，安装身份 **`com.ts.launcher`**（组件仍是 `com.gathin.tvhome/.MainActivity`）。
  CN 固件只允许白名单包名接管 HOME，标准 `com.gathin.tvhome` 身份会被静默拒绝（已实测）。
- 原桌面 PatchWall（`com.mitv.tvhome`）**停用**（未卸载）。
- 共 25 个包处于停用状态，其中 24 个来自 [debloat-packages.txt](debloat-packages.txt)，
  另有系统原本就停用的（见 `inventory/packages-disabled-after-reboot.txt`）。
- 保留：小爱语音、投屏（MiPlay / smartshare）、Mi Home + 电视管家、小米应用商店、全部流媒体。
- Dock：奇异果TV / 云视听极光 / 酷喵 / 芒果TV（改 `config.xml` 的 `dock_apps` 后重装，
  或用长按菜单在电视上直接换）。

## 全部恢复

```bash
export MSYS_NO_PATHCONV=1
TV_HOST=<电视IP>:5555

# 1. 恢复清单里的 24 个包（脚本会尊重停用前的状态）
tools/restore.sh device/xiaomi-mitv-mftr0/debloat-packages.txt com.mitv.tvhome

# 2. 恢复 PatchWall
adb shell pm enable com.mitv.tvhome

# 3. 要 OTA 就恢复系统更新
adb shell pm enable com.xiaomi.mitv.upgrade

# 4. 重启
adb reboot
```

重启后 HOME 回到 PatchWall；`com.ts.launcher` 可在 设置 → 应用 里卸载。

## 单点回滚

```bash
adb shell pm enable <包名>                                                  # 单个包
adb shell cmd package set-home-activity com.ts.launcher/com.gathin.tvhome.MainActivity   # 重设默认桌面
```

## 日常提醒

- 这台电视每次重启会关掉 ADB 调试：设置 → 账号与安全 → ADB 调试 重新打开，首次连接要在电视上勾"一律允许"。
- **确认一切正常后建议关闭 ADB 调试**（5555 是明文端口）。
